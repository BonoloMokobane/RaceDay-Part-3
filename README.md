# RaceDay

RaceDay is a web-based event management system designed for running, walking and cycling events. It allows participants and organisers to interact with events through a web application.

## Technologies Used

- C#
- ASP.NET Core Web API
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- Azure Blob Storage
- HTML and CSS

## Project Structure

- **RaceDay.API** – Backend API responsible for application functionality and data management.
- **RaceDay.MVC** – MVC web application providing the user interface.
- **RaceDay.API.Tests** – Project for API testing.

## Key Features

- User registration and login
- Organizer and participant roles
- Event management
- Event browsing
- Profile image uploads
- Event banner image uploads using Azure Blob Storage

## Getting Started

1. Clone or download the repository.
2. Open `RaceDay.sln` in Visual Studio.
3. Configure the required database connection and Azure Blob Storage settings.
4. Run the API and MVC projects.

**Note:** Keep connection strings, passwords and other sensitive configuration values out of GitHub.
